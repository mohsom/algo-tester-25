# Депутатські краватки

**Посилання на умову:** [Алготестер, задача 8](https://algotester.com/uk/ArchiveProblem/Display/8)

**Тема:** бінарний пошук за відповіддю

## Умова

Є `n` краваток довжин `a_i` і `m` депутатів. Краватки можна розрізати на довільну кількість частин. Потрібно, щоб кожен із `m` депутатів отримав краватку **однакової** довжини, і ця довжина була максимально можливою. Вивести цю довжину (похибка до 1e-4). Обмеження: n, m ≤ 1000, a_i ≤ 1e9.

## Алгоритм

Якщо з краваток можна нарізати `m` шматків довжини `L`, то й для будь-якої меншої довжини це можливо. Отже функція «підходить / не підходить» монотонна, і ми шукаємо найбільше `L` бінарним пошуком по дійсних числах. Перевірка для `L`: сума `floor(a_i / L)` по всіх краватках має бути ≥ `m`. Верхня межа пошуку - сума всіх довжин, поділена на `m`. Робимо 100 ітерацій, цього вистачає для потрібної точності.

**Складність:** O(n · 100)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 0008-deputy-neckties
node solution.js < input.txt
```

Вміст `input.txt`:

```
3 4
1 10 5
```

Очікуваний вивід:

```
3.3333333
```
