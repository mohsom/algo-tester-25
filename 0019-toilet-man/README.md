# Тойлет-мен: знайти істину

**Посилання на умову:** [Алготестер, задача 19](https://algotester.com/uk/ArchiveProblem/Display/19)

**Тема:** граф (сильна зв'язність)

## Умова

Орієнтований граф із `n` вершин і `m` ребер. Знайти вершину з найменшим номером, з якої можна дійти до всіх інших, або вивести `-1`. n, m ≤ 10^5.

## Алгоритм

Якщо вершина, що досягає всіх, існує, то її можна знайти так: запускаємо обходи в глибину з усіх ще не відвіданих вершин у порядку 1..n; корінь останнього обходу - єдиний кандидат `c`. Перевіряємо обходом з `c`, що він досягає всіх вершин (інакше `-1`). Якщо досягає, то будь-яка вершина, з якої можна дійти до `c`, теж досягає всіх (через `c`), і це саме та компонента сильної зв'язності, яку ми шукаємо. Знаходимо ці вершини обходом по зворотних ребрах від `c` і беремо найменший номер. Обходи реалізовані ітеративно, щоб не переповнити стек.

**Складність:** O(n + m)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 0019-toilet-man
node solution.js < input.txt
```

Вміст `input.txt`:

```
3 3
1 2
2 3
1 3
```

Очікуваний вивід:

```
1
```
