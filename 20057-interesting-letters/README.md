# Цікаве листування

**Посилання на умову:** [Алготестер, задача 20057](https://algotester.com/uk/ArchiveProblem/Display/20057)

**Тема:** реалізація

## Умова

Повідомлення довжини `n = k·k` записують у квадрат `k × k` діагональними лініями з верхнього лівого кута, а потім об'єднують рядки квадрата в один рядок (лист). За листом відновити початкове повідомлення. k ≤ 10.

## Алгоритм

У листі клітинка `(i, j)` квадрата - це символ `s[i·k + j]`. Початкове повідомлення читається клітинками в порядку запису: діагоналі за зростанням `d = i + j`, а всередині діагоналі - за зростанням `i` (зверху вниз). Обходимо клітинки в цьому порядку й склеюємо символи.

**Складність:** O(n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20057-interesting-letters
node solution.js < input.txt
```

Вміст `input.txt`:

```
9
124357689
```

Очікуваний вивід:

```
123456789
```
