# Конкурс талантів

**Посилання на умову:** [Алготестер, задача 20058](https://algotester.com/uk/ArchiveProblem/Display/20058)

**Тема:** повний перебір (префіксні суми)

## Умова

Гараж - це сітка `n × n` з нулів (вільно) і одиниць (мішок). Можна забрати не більше `k` мішків. Знайти найбільшу сторону квадрата зі сторонами, паралельними сторонам гаража, який можна повністю звільнити. n ≤ 10, k ≤ 10.

## Алгоритм

Будуємо двовимірні префіксні суми, щоб за O(1) отримувати кількість мішків у будь-якому квадраті. Перебираємо сторону квадрата від найбільшої до найменшої і для кожної - усі положення квадрата; перша знайдена сторона, при якій у якомусь квадраті не більше `k` мішків, і є відповідь (якщо жодна не підійшла, відповідь 0).

**Складність:** O(n³)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20058-talent-contest
node solution.js < input.txt
```

Вміст `input.txt`:

```
4 1
1011
0000
0010
1000
```

Очікуваний вивід:

```
3
```
