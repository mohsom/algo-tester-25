# Зуби

**Посилання на умову:** [Алготестер, задача 20075](https://algotester.com/uk/ArchiveProblem/Display/20075)

**Тема:** реалізація

## Умова

Задано `n` зубів з коефіцієнтами загостреності `a_i` та межа `k`. Зуб загострений, якщо `a_i ≥ k`. Знайти найбільшу кількість загострених зубів підряд. n ≤ 10^5.

## Алгоритм

Один прохід масивом з лічильником поточної серії: якщо `a_i ≥ k`, збільшуємо лічильник, інакше скидаємо в 0. Відповідь - максимум значень лічильника.

**Складність:** O(n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20075-sharp-teeth
node solution.js < input.txt
```

Вміст `input.txt`:

```
7 4
7 1 4 7 6 3 4
```

Очікуваний вивід:

```
3
```
