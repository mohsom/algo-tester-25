# Торт для Петрика

**Посилання на умову:** [Алготестер, задача 20078](https://algotester.com/uk/ArchiveProblem/Display/20078)

**Тема:** математика

## Умова

Торт складається з `n` циліндричних ярусів (дивимось зверху - це кола зі спільним центром, від найбільшого до найменшого). Видимі площі всіх ярусів мають бути рівні, радіус найбільшого - `r`. Знайти радіус найменшого. n, r ≤ 100.

## Алгоритм

Площа найбільшого кола `π r²` складається з `n` рівних видимих площ, а видима площа найменшого (верхнього) ярусу - це повна площа його кола. Тому `π R² = π r² / n`, звідки `R = r / √n`.

**Складність:** O(1)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20078-petryk-cake
node solution.js < input.txt
```

Вміст `input.txt`:

```
4 7
```

Очікуваний вивід:

```
3.5000000
```
