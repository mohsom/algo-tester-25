# Петрик і змійка

**Посилання на умову:** [Алготестер, задача 20079](https://algotester.com/uk/ArchiveProblem/Display/20079)

**Тема:** реалізація (множина відвіданих клітинок)

## Умова

Змійка рухається по нескінченній площині: починає в точці `(x, y)`, потім виконує ходи `L, R, U, D`. Тіло лишається на місці, тож довжина росте. Якщо голова потрапляє на клітинку, де вже була змійка, гра програна. Вивести `Success` або `Fail` і номер ходу першого зіткнення. |s| ≤ 10^6.

## Алгоритм

Тіло змійки - це всі клітинки, які вже відвідала голова. Зберігаємо їх у `Set` (координати кодуємо в одне число) і після кожного ходу перевіряємо, чи нова клітинка вже є в множині. Якщо так - виводимо `Fail` і номер ходу.

**Складність:** O(|s|)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20079-snake
node solution.js < input.txt
```

Вміст `input.txt`:

```
1 2
RRRUULLDRRD
```

Очікуваний вивід:

```
Fail
10
```
