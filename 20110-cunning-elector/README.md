# Курфюрста жахів

**Посилання на умову:** [Алготестер, задача 20110](https://algotester.com/uk/ArchiveProblem/Display/20110)

**Тема:** реалізація (лічильник)

## Умова

Є `n` подій: `In` - виборець зайшов у кабінку, `Out` - вийшов. Вивести `Cunning elector`, якщо хтось залишився, `Just a fantasy`, якщо нікого, або `Error`, якщо дані суперечливі. n ≤ 1000.

## Алгоритм

Підтримуємо лічильник виборців у кабінках: `In` збільшує, `Out` зменшує. Якщо лічильник стає від'ємним, хтось вийшов, коли нікого не було - `Error`. Інакше за кінцевим значенням: > 0 - `Cunning elector`, = 0 - `Just a fantasy`.

**Складність:** O(n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 20110-cunning-elector
node solution.js < input.txt
```

Вміст `input.txt`:

```
3
In
In
Out
```

Очікуваний вивід:

```
Cunning elector
```
