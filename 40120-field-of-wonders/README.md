# Поле чудес

**Посилання на умову:** [Алготестер, задача 40120](https://algotester.com/uk/ArchiveProblem/Display/40120)

**Тема:** рядки (множина)

## Умова

За хід називається літера, і відкриваються всі такі літери в слові. Знайти мінімальну кількість ходів, щоб відкрити слово повністю. |s| ≤ 100, великі латинські літери.

## Алгоритм

Одним ходом відкриваються всі входження літери, тож потрібно по одному ходу на кожну різну літеру. Відповідь - розмір множини літер слова.

**Складність:** O(|s|)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40120-field-of-wonders
node solution.js < input.txt
```

Вміст `input.txt`:

```
KOLOBOK
```

Очікуваний вивід:

```
4
```
