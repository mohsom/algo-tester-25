# Зробити паліндром

**Посилання на умову:** [Алготестер, задача 40140](https://algotester.com/uk/ArchiveProblem/Display/40140)

**Тема:** рядки (підрахунок частот)

## Умова

Дано рядок `s` з малих латинських літер, літери можна переставляти. Чи можна отримати паліндром? Вивести `YES` або `NO`. |s| ≤ 10^5.

## Алгоритм

Паліндром можна скласти, якщо кожна літера, крім щонайбільше однієї (посередині), зустрічається парну кількість разів. Рахуємо кількість кожної літери й перевіряємо, що літер із непарною кількістю не більше однієї.

**Складність:** O(|s|)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40140-make-palindrome
node solution.js < input.txt
```

Вміст `input.txt`:

```
aabbbb
```

Очікуваний вивід:

```
YES
```
