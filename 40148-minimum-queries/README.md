# Мінімум

**Посилання на умову:** [Алготестер, задача 40148](https://algotester.com/uk/ArchiveProblem/Display/40148)

**Тема:** структури даних (дерево Фенвіка)

## Умова

Масив із `n` чисел і `q` запитів: `query s f` - сума елементів на `[s, f]`, `change p v` - замінити елемент `p` на `v`. n, q ≤ 111111.

## Алгоритм

Те саме, що й у задачі про прості запити: дерево Фенвіка для префіксних сум. Заміна значення реалізується як додавання різниці `v - a[p]`, для чого окремо зберігаємо поточні значення масиву `a`.

**Складність:** O((n + q) log n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40148-minimum-queries
node solution.js < input.txt
```

Вміст `input.txt`:

```
10 5
9 10 9 8 6 8 6 6 1 3
query 1 3
change 8 2
change 6 6
query 1 7
query 1 2
```

Очікуваний вивід:

```
28
54
19
```
