# Аркуш

**Посилання на умову:** [Алготестер, задача 40174](https://algotester.com/uk/ArchiveProblem/Display/40174)

**Тема:** математика (комбінаторика)

## Умова

Квадратний аркуш у клітинку має `n × n` клітинок. Порахувати, скільки всього квадратів утворюють лінії розмітки. n ≤ 1000.

## Алгоритм

Квадратів зі стороною `k` у сітці `n × n` рівно `(n - k + 1)²`. Сума по всіх `k` від 1 до `n` дорівнює `1² + 2² + ... + n² = n(n+1)(2n+1)/6`.

**Складність:** O(1)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40174-paper-sheet
node solution.js < input.txt
```

Вміст `input.txt`:

```
3
```

Очікуваний вивід:

```
14
```
