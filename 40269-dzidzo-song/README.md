# Дзідзьо і його пісня

**Посилання на умову:** [Алготестер, задача 40269](https://algotester.com/uk/ArchiveProblem/Display/40269)

**Тема:** рядки

## Умова

Із рядка `s` видаляють рівно один символ. Скільки існує різних рядків, які можуть утворитись? 2 ≤ |s| ≤ 100.

## Алгоритм

Видалення будь-якого символу з однієї серії однакових літер дає той самий рядок, а видалення символів із різних серій дає різні рядки. Отже, відповідь - кількість серій (максимальних груп однакових літер підряд), тобто 1 плюс кількість позицій, де `s[i] != s[i-1]`.

**Складність:** O(|s|)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40269-dzidzo-song
node solution.js < input.txt
```

Вміст `input.txt`:

```
aabbbc
```

Очікуваний вивід:

```
3
```
