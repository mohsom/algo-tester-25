# Свічки на Halloween

**Посилання на умову:** [Алготестер, задача 40306](https://algotester.com/uk/ArchiveProblem/Display/40306)

**Тема:** бінарний пошук за відповіддю

## Умова

Є `m` свічок довжин `l_i` та `n` гарбузів. Свічки можна розрізати, але не склеювати, у кожен гарбуз потрібна свічка однакової довжини. Знайти максимально можливу довжину. n, m, l_i ≤ 100, похибка до 1e-7.

## Алгоритм

Бінарний пошук за відповіддю по дійсних числах: для довжини `len` з кожної свічки виходить `floor(l_i / len)` шматків, і `len` підходить, якщо їх сумарно не менше `n`. Якщо `len` підходить, то й менша довжина підходить, тож умова монотонна. Робимо 100 ітерацій.

**Складність:** O(m · 100)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40306-halloween-candles
node solution.js < input.txt
```

Вміст `input.txt`:

```
4 3
1 4 2
```

Очікуваний вивід:

```
1.33333333
```
