# НСК

**Посилання на умову:** [Алготестер, задача 40467](https://algotester.com/uk/ArchiveProblem/Display/40467)

**Тема:** теорія чисел

## Умова

Знайти найменше спільне кратне трьох чисел `a, b, c` (кожне ≤ 10^6).

## Алгоритм

Використовуємо `lcm(x, y) = x / gcd(x, y) · y` і рахуємо `lcm(lcm(a, b), c)`. НСД знаходимо алгоритмом Евкліда. Результат може сягати 10^18 і не вміщується точно в `Number`, тому всі обчислення робимо в `BigInt`.

**Складність:** O(log max)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40467-lcm-three
node solution.js < input.txt
```

Вміст `input.txt`:

```
3 1 2
```

Очікуваний вивід:

```
6
```
