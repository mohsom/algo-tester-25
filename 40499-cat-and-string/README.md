# Котик та рядок символів

**Посилання на умову:** [Алготестер, задача 40499](https://algotester.com/uk/ArchiveProblem/Display/40499)

**Тема:** рядки

## Умова

Поки в рядку є дві однакові літери поруч, котик нявкає, а Зеник уставляє в довільне місце довільну літеру. Скільки мінімум разів нявкне котик? |s| ≤ 1000.

## Алгоритм

Кожна пара сусідніх однакових літер `s[i] == s[i+1]` потребує окремої вставки між ними (вставка в серію з L однакових літер розриває лише одну пару, тож серія довжини L потребує L - 1 вставок). Вставляти слід літеру, відмінну від обох сусідів, тоді нових пар не виникає. Відповідь - кількість позицій, де літера дорівнює попередній.

**Складність:** O(|s|)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40499-cat-and-string
node solution.js < input.txt
```

Вміст `input.txt`:

```
VITALIILOVESSEVENSANDFOURSWOOOOOOW
```

Очікуваний вивід:

```
7
```
