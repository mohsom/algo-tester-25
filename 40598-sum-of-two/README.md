# Сума двох

**Посилання на умову:** [Алготестер, задача 40598](https://algotester.com/uk/ArchiveProblem/Display/40598)

**Тема:** бінарний пошук

## Умова

Дано послідовності `a` (n елементів) і `b` (m елементів). Вибрати по одному числу з кожної так, щоб `|a_i + b_j - x|` було мінімальним, і вивести це мінімальне значення. n, m ≤ 10^5, значення до 10^18.

## Алгоритм

Сортуємо `b`. Для кожного `a_i` бінарним пошуком знаходимо в `b` перший елемент, що не менший за `x - a_i`. Найближча до цілі сума утворюється з цим елементом або з його попередником у відсортованому масиві, тому перевіряємо обидва варіанти й беремо мінімум. Значення до 10^18 не вміщуються точно в `Number`, тому використовуємо `BigInt`.

**Складність:** O((n + m) log m)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40598-sum-of-two
node solution.js < input.txt
```

Вміст `input.txt`:

```
4 3 7
1 4 2 10
7 3 8
```

Очікуваний вивід:

```
0
```
