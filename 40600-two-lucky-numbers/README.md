# Два щасливих числа

**Посилання на умову:** [Алготестер, задача 40600](https://algotester.com/uk/ArchiveProblem/Display/40600)

**Тема:** повний перебір (попереднє обчислення)

## Умова

Щасливі числа складаються лише з цифр 4 і 7. Для кожного з `q` запитів визначити, чи можна подати `x` у вигляді суми двох щасливих чисел. x ≤ 10^9, q ≤ 100.

## Алгоритм

Щасливих чисел до 10^9 лише 1022 (по 2^k на кожну довжину). Генеруємо їх рекурсивно, обчислюємо всі попарні суми (приблизно 500 тисяч значень) і зберігаємо в `Set`. Кожен запит - це перевірка належності числа множині за O(1).

**Складність:** O(L²), де L = 1022 - кількість щасливих чисел

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40600-two-lucky-numbers
node solution.js < input.txt
```

Вміст `input.txt`:

```
5
8
47
48
11
450
```

Очікуваний вивід:

```
YES
NO
YES
YES
NO
```
