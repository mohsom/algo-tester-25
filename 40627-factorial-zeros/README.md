# Факторіал

**Посилання на умову:** [Алготестер, задача 40627](https://algotester.com/uk/ArchiveProblem/Display/40627)

**Тема:** теорія чисел

## Умова

Знайти кількість нулів у кінці десяткового запису `n!`. n ≤ 2·10^9.

## Алгоритм

Кожен нуль у кінці - це пара множників 2 і 5, а двійок у факторіалі завжди більше, ніж п'ятірок. Тому кількість нулів дорівнює показнику степеня 5 у розкладі `n!`, який рахується як `⌊n/5⌋ + ⌊n/25⌋ + ⌊n/125⌋ + ...`.

**Складність:** O(log₅ n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40627-factorial-zeros
node solution.js < input.txt
```

Вміст `input.txt`:

```
8
```

Очікуваний вивід:

```
1
```
