# Центральна дільниця

**Посилання на умову:** [Алготестер, задача 40794](https://algotester.com/uk/ArchiveProblem/Display/40794)

**Тема:** граф (алгоритм Дейкстри)

## Умова

Граф із `n` вершин і `m` зважених ребер (довжини доріг, 1..1000). Із кожної дільниці треба відправити вантажівку до дільниці 1. Знайти мінімальну сумарну відстань. n, m ≤ 10^5.

## Алгоритм

Ваги додатні, тож за найкоротші відстані від дільниці 1 до всіх інших відповідає алгоритм Дейкстри з двійковою купою. Оскільки граф неорієнтований, шлях від вершини до центру має ту саму довжину, що й від центру до вершини. Відповідь - сума знайдених відстаней.

**Складність:** O((n + m) log n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40794-central-station
node solution.js < input.txt
```

Вміст `input.txt`:

```
5 6
1 2 3
1 4 2
1 3 7
2 5 1
2 3 1
4 5 1
```

Очікуваний вивід:

```
12
```
