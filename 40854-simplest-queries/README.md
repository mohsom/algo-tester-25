# Найпростіші запити

**Посилання на умову:** [Алготестер, задача 40854](https://algotester.com/uk/ArchiveProblem/Display/40854)

**Тема:** структури даних (дерево Фенвіка)

## Умова

Масив із `n` чисел і `m` запитів: знайти суму на відрізку `[l, r]` або додати `d` до `i`-го елемента. n, m ≤ 10^5.

## Алгоритм

Для запитів «зміна точки + сума на відрізку» використовуємо дерево Фенвіка (BIT): `add(i, d)` оновлює `O(log n)` вузлів, `prefix(i)` складає префіксну суму за `O(log n)`. Сума на відрізку - це `prefix(r) - prefix(l - 1)`.

**Складність:** O((n + m) log n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd 40854-simplest-queries
node solution.js < input.txt
```

Вміст `input.txt`:

```
8 3
1 4 2 1 7 3 5 2
1 2 6
2 4 4
1 2 6
```

Очікуваний вивід:

```
17
21
```
