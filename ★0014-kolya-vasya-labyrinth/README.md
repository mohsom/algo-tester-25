# ★ Коля, Вася і лабіринт

**Посилання на умову:** [Алготестер, задача 14](https://algotester.com/uk/ArchiveProblem/Display/14)

**Задача для захисту** ★ (граф)

**Тема:** граф (пошук вершин циклу)

## Умова

Офіс - це `n` кімнат і `n` двосторонніх проходів, між будь-якими двома кімнатами існує шлях і проходів між парою не більше одного. Вивести всі кімнати, які належать хоча б одному циклу (кількість і номери за зростанням). Обмеження: n ≤ 10^5.

## Алгоритм

Зв'язний граф, у якого кількість ребер дорівнює кількості вершин, містить рівно один цикл, а решта вершин - дерева, що «звисають» з цього циклу. Тому послідовно видаляємо листки: кладемо в чергу всі вершини ступеня 1, прибираємо їх і зменшуємо ступінь сусіда; коли ступінь сусіда стає 1, він теж потрапляє в чергу. Вершини, які не були видалені, - це рівно вершини циклу.

**Складність:** O(n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd ★0014-kolya-vasya-labyrinth
node solution.js < input.txt
```

Вміст `input.txt`:

```
4
1 2
2 3
3 4
4 2
```

Очікуваний вивід:

```
3
2 3 4
```
