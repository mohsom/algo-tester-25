# ★ Реплікація. Частина 1

**Посилання на умову:** [Алготестер, задача 40772](https://algotester.com/uk/ArchiveProblem/Display/40772)

**Задача для захисту** ★ (бінарне дерево (купа))

**Тема:** бінарне дерево (бінарна купа)

## Умова

Генетичне дерево - це двійкова купа, де батьківський ген не коротший за дочірні. Є запити `+ a` (додати ген розміру `a`) і `-` (видалити кореневий ген, замінивши його останнім в ієрархії). Після кожного запиту вивести кількість обмінів («заміщень»), виконаних під час відновлення властивості купи, і розмір кореня. Спочатку в дереві один ген розміру `p`. n ≤ 10^5.

## Алгоритм

Емулюємо бінарну max-купу в масиві: діти вершини `i` - це `2i+1` і `2i+2`. Додавання: кладемо елемент у кінець і піднімаємо вгору, поки він більший за батька (`siftUp`), рахуючи обміни. Видалення кореня: забираємо останній елемент масиву, ставимо його в корінь і опускаємо вниз, щоразу обмінюючись із більшим із дітей, якщо той більший за поточний (`siftDown`), рахуючи обміни. Після кожної операції виводимо кількість обмінів і `heap[0]`.

**Складність:** O(n log n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd ★40772-replication-heap
node solution.js < input.txt
```

Вміст `input.txt`:

```
5 43
+ 23
+ 15
-
+ 4
-
```

Очікуваний вивід:

```
0 43
0 43
1 23
0 23
1 15
```
