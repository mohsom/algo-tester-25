# ★ Екстрене завдання

**Посилання на умову:** [Алготестер, задача 71154](https://algotester.com/uk/ArchiveProblem/Display/71154)

**Задача для захисту** ★ (sliding window)

**Тема:** sliding window (два вказівники)

## Умова

Масив із `n` цілих чисел. Порахувати кількість підмасивів (неперервних послідовностей), у яких щонайменше `k` **різних** значень. Обмеження: 1 ≤ k ≤ n ≤ 2·10^5.

## Алгоритм

Рахуємо від зворотного: усіх підмасивів `n(n+1)/2`, від них віднімаємо кількість підмасивів, у яких **менше** `k` різних значень (тобто не більше `k-1`). Для підрахунку підмасивів із не більше ніж `limit` різних значень використовуємо ковзне вікно `[left, right]` з лічильником елементів у `Map`: розширюємо правий край, а доки різних більше за `limit` - зсуваємо лівий. Усі підмасиви, що закінчуються в `right` і починаються від `left`, підходять, їх `right - left + 1`.

**Складність:** O(n)

## Запуск

Команди виконуються з кореня репозиторію (`input.txt` містить приклад з умови):

```bash
cd ★71154-emergency-task
node solution.js < input.txt
```

Вміст `input.txt`:

```
7 4
1 2 2 3 4 1 2
```

Очікуваний вивід:

```
8
```
